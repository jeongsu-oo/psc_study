 일급 비밀 보안 시스템

 사용 범위: 변수 / 자료형 / 형변환 / 입출력 / 연산자 / 조건문

 ※ 반복문, 리스트, 함수, 문자열 인덱싱은 사용 금지

=========================================================

당신은 적 기지에 잠입한 특수 요원입니다.

메인 서버실로 가는 마지막 보안 문은 3중 잠금 장치로 보호되고 있습니다.

제한 시간 안에 모든 관문을 통과하십시오.

---------------------------------------------------------

 [1단계] 요원 정보 입력

---------------------------------------------------------

input()으로 아래 5가지를 순서대로 입력받고, 알맞게 형변환하세요.

  ① 요원 코드명        (문자열)   예: Falcon

  ② 5자리 보안 코드     (정수)     예: 84269

  ③ 마스터키 등급       (문자열)   "S" / "A" / "N" 중 하나

  ④ 현재 체온          (실수)     예: 36.5

  ⑤ 남은 시간(초)      (정수)     예: 200

※ 어떤 값에 int()를 씌우고 어떤 값에 안 씌우는지 정확히 판단하세요.

---------------------------------------------------------

 [2단계] 보안 코드 분해

---------------------------------------------------------

5자리 코드를 만의 자리 / 천의 자리 / 백의 자리 / 십의 자리 / 일의 자리

다섯 개의 변수로 분리하세요.

※ 문자열 인덱싱은 아직 배우지 않았습니다.

   오직 // (몫) 와 % (나머지) 만으로 수학적으로 분리해야 합니다.

예) 84269  →  8, 4, 2, 6, 9

---------------------------------------------------------

 [3단계] 0차 검문 - 복제 코드 판별  ★ 가장 먼저 검사

---------------------------------------------------------

적이 만든 위조 코드는 '앞뒤가 대칭'이라는 특징이 있습니다.

  대칭 조건: 만의 자리 == 일의 자리  그리고  천의 자리 == 십의 자리

  (백의 자리는 가운데이므로 상관없음)

  예) 84248 → 8==8, 4==4  → 복제 코드!

대칭이면 아래 내용을 무시하고 즉시 실패 처리합니다.

 출력: "복제된 코드 감지! 즉시 폐쇄합니다."

---------------------------------------------------------

 [4단계] 1차 보안 - 등급별 논리 판정

---------------------------------------------------------

세 가지 조건을 각각 판별하세요.

  조건 A : (만의 자리 + 천의 자리) >= (십의 자리 + 일의 자리)

  조건 B : 보안 코드 전체가 짝수이거나 3의 배수

  조건 C : 백의 자리 숫자가 홀수

통과 기준은 마스터키 등급에 따라 달라집니다.

  등급 "S" : 조건 A 만 만족하면 통과

  등급 "A" : 조건 A 를 만족하고, B 와 C 중 하나 이상 만족하면 통과

  등급 "N" : 조건 A, B, C 를 모두 만족해야 통과

  그 외 입력 : 잘못된 등급 → 무조건 실패

실패 시 출력: "보안 시스템 작동! 침입자를 체포하라!"

※ 힌트: 조건이 세 개나 되므로, 판별 결과를 변수에 담아두면 편합니다.

         예)  cond_a = (d1 + d2) >= (d4 + d5)

         비교 연산의 결과는 True/False이므로 변수에 그대로 저장됩니다.

---------------------------------------------------------

 [5단계] 2차 보안 - 생체 인식  (1차 통과 시에만)

---------------------------------------------------------

체온에 따라 상태를 세 가지로 나눕니다.

  정상 : 36.0 이상 37.5 이하

  주의 : 35.0 이상 38.5 이하 이면서 '정상'이 아닌 경우

  위독 : 그 외 (35.0 미만 또는 38.5 초과)

※ elif 순서를 잘못 짜면 '주의'가 영영 나오지 않습니다. 주의하세요.

── 위험도 계산 ──

  보안 코드의 자릿수는 각각 이런 뜻을 가집니다.

    만의 자리 → 잠입 깊이   (깊이 들어갈수록 위험)

    천의 자리 → 경비 밀도   (경비가 많을수록 위험)

    십의 자리 → 탈출로 개수 (도망칠 길이 많을수록 안전)

  그래서 위험도는 이렇게 계산합니다.

    기본 위험도 = (만의 자리 * 천의 자리) / (십의 자리 + 1)

                   └── 위험 요소 ──┘      └ 안전 요소 ┘

  위험한 것끼리는 곱하고, 안전한 것으로는 나눕니다.

  탈출로가 많을수록 나누는 수가 커지므로 위험도가 내려갑니다.

  ※ 왜 하필 '+ 1' 일까요?

     탈출로가 하나도 없는 코드(십의 자리 = 0)를 생각해 보세요.

     + 1 이 없으면 0 으로 나누게 되고, 파이썬은 이때

     ZeroDivisionError 를 내면서 프로그램이 그 자리에서 멈춰버립니다.

     "0이 될 수 있는 값으로 나눌 때는 미리 막아둔다" 는 것은

     실제 프로그램에서도 늘 쓰는 방법입니다.

  ※ / 로 나눈 결과는 나누어떨어져도 항상 실수(float)입니다.

     18 이 아니라 18.0 이 나오는 이유입니다. (몫만 필요하면 // 를 씁니다)

  상태가 '정상' : 기본 위험도 그대로

  상태가 '주의' : 몸이 성치 않으니 더 위험합니다 → 기본 위험도에 1.5배

  상태가 '위독' : 측정 자체가 불가능합니다 → 계산하지 않고 위험도에 None 저장

'위독'이면 아래 6단계를 건너뛰고 즉시 출력합니다.

 출력: "생체 신호 위독! 의무실로 강제 이송합니다. (위험도: 측정 불가)"

---------------------------------------------------------

 [6단계] 3차 보안 - 시간 제한  (2차 통과 시에만)

---------------------------------------------------------

위험도가 높을수록 문을 여는 데 시간이 더 걸립니다.

  위험도가 50 이상 : 필요 시간 180초

  위험도가 50 미만 : 필요 시간 60초

남은 시간이 필요 시간보다 적으면 실패입니다.

  부족한 시간 = 필요 시간 - 남은 시간

  출력: "시간 초과! 문이 다시 잠겼습니다. (부족한 시간: 1분 05초)"

※ 초를 '분과 초'로 바꿀 때도 // 와 % 를 사용하세요.

※ 초는 항상 두 자리로 출력해야 합니다. (5초 → 05초)

   ※ 힌트: f"{값:02d}" 를 쓰면 두 자리로 맞춰지고 빈 자리는 0으로 채워집니다.

---------------------------------------------------------

 [7단계] 최종 출력

---------------------------------------------------------

모든 관문을 통과했다면 아래 형식으로 출력하세요.

  "[Falcon] 서버실 개방! 상태: 정상 / 위험도: 12.50 / 잔여 2분 20초"

※ 잔여 시간 = 남은 시간 - 필요 시간

   문을 여는 데 '필요 시간'을 썼으므로 그만큼 빼야 합니다.

   (예: 남은 200초, 필요 60초 → 잔여 140초 → "2분 20초")

※ 위험도는 소수점 둘째 자리까지 표시합니다.

※ 코드명은 대괄호로 감싸 출력합니다.
