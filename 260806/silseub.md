파이썬 종합 연습문제 20제

변수 / 자료형 변환 / 입출력 / 연산자 / 조건문 / 딕셔너리

================================================================

 

사용 O : 변수, input(), print(), int() float() str(), 산술연산자,

         비교연산자, 논리연산자(and or not), if / elif / else,

         리스트, 딕셔너리

         (딕셔너리 안에 딕셔너리, 딕셔너리 안에 리스트가 들어갑니다)

사용 X : for 문, while 문, 함수 정의(def)

 

[입력 안내]

  - 값은 input() 으로 직접 받으세요.

  - input() 은 항상 문자열을 돌려줍니다. 숫자로 계산하려면 반드시 변환하세요.

  - 입력 안내 문구는 자유롭게 작성해도 됩니다.

  - 아래 <입력값> 은 채점 기준 예시입니다. 다른 값으로도 테스트하세요.

  - 출력 문구는 예시와 똑같지 않아도 됩니다. 필요한 정보가 나오면 정답입니다.

 

[공통 가정]

  - 숫자를 입력하라는 문제에서는 항상 올바른 형태의 숫자가 입력된다고 가정합니다.

    ("abc" 같은 잘못된 입력은 처리하지 않아도 됩니다.)

  - 나누기를 하는 문제에서 0 은 입력하지 않는다고 가정합니다.

  - 딕셔너리 자료는 문제에 주어진 것을 그대로 복사해서 사용하세요.

[문제 6] BMI 계산기

----------------------------------------------------------------

몸무게(kg)와 키(m)를 입력받아 BMI 를 소수점 둘째 자리까지 계산하세요.

  BMI = 몸무게 / (키 * 키)

 

판정 기준

  18.5 미만          -> 저체중

  18.5 이상 23 미만  -> 정상

  23 이상 25 미만    -> 과체중

  25 이상            -> 비만

 

계산한 BMI 와 판정 결과를 딕셔너리에 담아 출력하고,

딕셔너리에서 값을 꺼내 한 줄 요약도 출력하세요.

 

<입력값>

65.5

1.75

 

<출력 예시>

{'bmi': 21.39, '판정': '정상'}

BMI 21.39 -> 정상

[문제 8] 온도 변환과 날씨 안내

섭씨온도는 소수점이 있을 수 있으므로 실수로 변환해 사용하세요.

  화씨 = 섭씨 * 9 / 5 + 32

 

이어서 아래 기준으로 안내 문구를 출력합니다.

  28도 이상           -> 무더위입니다.

  15도 이상 28도 미만 -> 활동하기 좋은 날씨입니다.

  15도 미만           -> 쌀쌀합니다.

 

<입력값>

25

 

<출력 예시>

섭씨 25.0도 = 화씨 77.0도

활동하기 좋은 날씨입니다.

[문제 20] 학급 명단 조회

----------------------------------------------------------------

반 이름과 번호를 입력받아 아래 정보를 출력하세요.

  담임 선생님 / 학생 수 / 해당 번호의 학생 이름

 

없는 반이면 안내 문구를 출력하고,

번호가 학생 수 범위를 벗어나면 안내 문구를 출력하세요.

(번호는 1번부터 시작합니다)

 

school = {

    "3학년": {

        "1반": {"teacher": "박선생", "students": ["김철수", "이영희", "박민수"]},

        "2반": {"teacher": "최선생", "students": ["정수진", "한동훈"]},

    }

}

 

<입력값>

1반

2

 

<출력 예시>

3학년 1반 담임: 박선생

학생 수: 3

2번 학생: 이영희

 

※ "5반" 과, 1반의 7번을 입력해 나머지 두 갈래도 확인할 것
